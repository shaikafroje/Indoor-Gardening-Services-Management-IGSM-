# Indoor Gardening Services Management (IGSM)

## PHASE 1 --- Requirement Analysis & Planning

**Complexity:** Medium\
**Duration:** 40m

### Description

In this phase, the project requirements are gathered by identifying user
needs, business objectives, and the overall scope of the Indoor
Gardening Services Management (IGSM) application. Functional and
non-functional requirements are analyzed, and the system workflow, user
roles, and key features are planned. A detailed project roadmap is then
prepared to ensure smooth development and successful implementation.

### Activities

-   Activity: 1 Business Objective
-   Activity: 2 Functional Scope
-   Activity: 3 Stakeholder Mapping
-   Activity: 4 Execution Roadmap (Milestones)

### Activity: 1 Business Objective

**Duration:** 10m\
**Assigned to:** Ponnuru Shaik Afroje\
**Status:** In Progress

#### Description

The primary objective of the Indoor Gardening Services Management (IGSM)
project is to digitize and automate the process of managing indoor
gardening services. The application aims to simplify service requests,
automate approvals and task assignments, ensure timely maintenance
through SLA tracking, and improve operational efficiency while enhancing
customer satisfaction.

### Activity: 2 Functional Scope

**Duration:** 10m\
**Assigned to:** Ponnuru Shaik Afroje\
**Status:** In Progress

#### Description

The Indoor Gardening Services Management (IGSM) application enables
users to submit gardening service requests, schedule plant maintenance,
track request status, and manage technician assignments. It includes
automated workflows for approvals, notifications, SLA monitoring, and
role-based access control. The system also provides reports and
dashboards to monitor service performance and overall operational
efficiency.

## PHASE 2 --- Backend Development & Configuration

**Complexity:** Medium\
**Duration:** 10m

### Description

In this phase, the backend components of the Indoor Gardening Services
Management (IGSM) application are developed and configured. Custom
tables, fields, relationships, user roles, and ACLs are created to
manage application data securely. Business Rules, Flow Designer, and SLA
configurations are implemented to automate processes and ensure
efficient service management.

**Complexity:** Medium\
**Duration:** 10m

### Description
